Luật chơi

  • AGENTS.mdluật lõi, agent đọc mỗi phiên

  • roles/thẻ vai thực thi và kiểm định
  • tiers/ba tier, bảng tier → model

Năng lực

  • skills/32 skill, agent tự gọi theo tình huống
