Cài đặt và dùng

Để agent cài giúp, hoặc tự làm trên Claude Code, Codex, Antigravity. Cần Git, Python 3.9+ và quyền đọc repo (đang private).

Cài đặt và dùng

Cài trên máy của bạn

  • 1Cần: Git và Python 3.9+. Ba script không cần cài gói nào (chỉ pytest khi muốn chạy bộ test của repo).
  • 2Harness: Claude Code, Codex hoặc Antigravity.
  • 3Quyền: quyền đọc repo trên GitHub (repo đang private).

Repo đang private. Bạn cần quyền đọc github.com/ducnguyen221/agent-agile-team mới clone được; chưa có quyền thì phần cài dưới đây chưa dùng được.

Cách nhanh nhất: để agent cài

Dán prompt ở cuối INSTALL.md vào Claude Code, Codex hoặc Antigravity. Agent đọc file đó, làm lần lượt, và hỏi trước mỗi lần cài phần mềm, sửa file luật của harness hay đặt biến môi trường. Cài xong agent chép nguyên dòng cuối của check.py --self cho bạn.

Tự làm — bước chung

Clone repo về thư mục nhà. Windows PowerShell 5.1 không mở ~ cho git, python, claude — dùng "$HOME\agent-agile-team". Trên macOS mọi lệnh python là python3.

Kiểm sau khi cài

Dòng cuối có → Đạt là lõi nguyên vẹn. Rồi mở phiên mới và hỏi agent: “luật lõi agent-agile-team nói gì về hai cổng?” — trả lời đúng là luật đã nạp.

macOS · bash
git clone https://github.com/ducnguyen221/agent-agile-team ~/agent-agile-team
Windows · PowerShell
git clone https://github.com/ducnguyen221/agent-agile-team "$HOME\agent-agile-team"
Kiểm sau khi cài · macOS
cd ~/agent-agile-team && python3 scripts/check.py --self
Kiểm sau khi cài · Windows
python "$HOME\agent-agile-team\scripts\check.py" --self --root "$HOME\agent-agile-team"

Điểm cắm (tuỳ chọn)

Không đặt gì repo vẫn chạy. Muốn cố định thì đặt biến ở mức tài khoản, trỏ file ngoài repo, rồi mở phiên mới.

Dùng lần đầu trong dự án của bạn

Chạy trong thư mục dự án. init không ghi đè file có sẵn; chạy lại không đổi gì.

Thư mục dự án · bash
python3 ~/agent-agile-team/scripts/init.py .            # chạy thử: in sẽ tạo gì, không ghi
python3 ~/agent-agile-team/scripts/init.py . --apply    # tạo .agile.json + REQUESTS, SPRINTS, SPECS
python3 ~/agent-agile-team/scripts/check.py docs/plans  # kiểm hồ sơ sprint
python3 ~/agent-agile-team/scripts/index.py .           # sinh lại khối "Đang mở"

Sau đó giao việc bằng lời thường — ví dụ “Dùng agent-agile-team: thêm chức năng tra cứu đơn theo mã cho dự án này.” — và đọc tiếp GUIDE.md. Cập nhật: git pull --ff-only trong bản clone (Claude Code thêm claude plugin marketplace update agent-agile-team và claude plugin update agent-agile-team@agent-agile-team). Gỡ không xoá sổ gốc hay hồ sơ sprint của dự án.
