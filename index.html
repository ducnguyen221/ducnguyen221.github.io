Mình vibe code thế nào?

Quy trình phát triển phần mềm siêu chuẩn chỉ, không một dòng code tay, được bảo chứng bởi sự kiên nhẫn và đám bạn AI. ☕

1

💡 1. Mơ mộng

Ngồi nghĩ ra một tính năng cực kỳ bay bổng hoặc một hiệu ứng thật lung linh, bất chấp việc mình có biết viết code hay không.

2

✍️ 2. Ra lệnh

Mở Claude Code lên, gõ tiếng Việt tự nhiên kiểu: "Dựng cho mình một trang terminal đẹp như phim viễn tưởng để duyệt các dự án GitHub".

3

🤖 3. AI cày cuốc

AI bắt đầu phân tích cấu trúc, cặm cụi tạo file, sửa logic CSS và HTML. Mình chỉ cần nhâm nhi cafe và xem code tự chạy rầm rầm.

4

🔄 4. "Không, sửa lại!"

Chạy thử, thấy chưa ưng mắt hoặc có lỗi. Mình bảo: "Không, đổi màu nền xịn hơn, làm card nổi bật hơn". Lặp lại đến khi ưng ý.

💬 "Nhìn thì hiện đại thế thôi chứ mình lười lắm. Mình chỉ là người biết đặt câu hỏi và kiên nhẫn uống cafe đợi AI làm."

Ới mình ở đâu?

Nếu thấy gì đó hay ho, hoặc đơn giản là muốn rủ mình chơi board game, bóng bàn, pickleball, hay cafe chém gió về Data và AI, cứ thoải mái ping mình nhé. Mình không bán khóa học hay nhận dự án outsource đâu, chỉ muốn kết bạn thôi! ☕
