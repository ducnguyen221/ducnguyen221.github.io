Cài đặt

Lấy mã nguồn, chạy thử, biết là đã đúng

Bạn cần Windows, Python 3.12 trở lên và Git; không cần thư viện ngoài. Mã nguồn nằm trong repo riêng, nên bạn phải được tác giả cấp quyền đọc trước khi tải.

Cài từ mã nguồn

Đây là cách cài duy nhất: công cụ chạy thẳng từ thư mục mã nguồn, không cài vào Python của máy.

1

Xin quyền đọc repo

Repo ducnguyen221/agent-investing-team là riêng tư. Liên hệ tác giả qua ducnguyen.vn, kèm tài khoản GitHub của bạn.

2

Kiểm Python

Mở PowerShell; kết quả phải là Python 3.12 trở lên.

PowerShell
python --version
3

Lấy mã nguồn bản 0.1.0

Đăng nhập GitHub bằng tài khoản đã được cấp quyền. Lệnh lấy nhánh chính; tên thư mục ghi số bản để bạn dễ nhận.

PowerShell
# bản 0.1.0
git clone https://github.com/ducnguyen221/agent-investing-team.git agent-investing-team-0.1.0
cd agent-investing-team-0.1.0

Cảnh báo: đừng đặt mã nguồn hay thư mục làm việc trong OneDrive, ổ mạng hoặc ổ SUBST. Công cụ từ chối những đường dẫn này.

Kiểm sau khi cài

Chạy bộ kiểm thử đi kèm từ thư mục mã nguồn. Cài đúng khi dòng cuối là OK.

PowerShell
python -m unittest discover -s tests
# đúng khi dòng cuối in: OK

Nâng cấp và gỡ

Nâng cấp

Lấy bản mới nhất từ nhánh chính, rồi chạy lại bộ kiểm thử.

PowerShell
git -C agent-investing-team-0.1.0 pull

Gỡ

Công cụ không cài gì vào máy. Xoá thư mục mã nguồn và các thư mục làm việc bạn đã tạo là xong.

PowerShell
Remove-Item -Recurse .\agent-investing-team-0.1.0

Lỗi hay gặp

git clone báo không tìm thấy repo?

Kiểm bạn đã đăng nhập GitHub đúng tài khoản được cấp quyền. Repo riêng tư nên khách chưa có quyền sẽ thấy lỗi này.

PowerShell không nhận lệnh python?

Cài Python 3.12 trở lên và chọn thêm vào PATH, hoặc thay python bằng py -3.12.

Báo Invalid input: platform?

Bạn đang chạy ngoài Windows. Công cụ chỉ xuất kết quả trên Windows.

Cài xong rồi?

Chạy lần nghiên cứu đầu tiên với snapshot mẫu đi kèm.
