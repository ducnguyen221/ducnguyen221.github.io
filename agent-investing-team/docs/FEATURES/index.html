Tính năng — agent-investing-team

Nguyên mẫu CLI Python nghiên cứu quỹ trên snapshot giá tổng hợp. Đọc một file JSON, chạy quy tắc minh hoạ xác định, ghi báo cáo và manifest băm vào thư mục làm việc ngoài repo. Không mạng, không dữ liệu live.

Không phải tư vấn đầu tư. Không có lệnh giao dịch. Kết quả kiểm thử phần mềm không chứng minh hiệu quả đầu tư hay độ chính xác dự báo.

1. Kiểm snapshot

KiểmHành vi
Kích thướcJSON ≤ 1 MiB, sâu ≤ 12 cấp, ≤ 1.000 nến
Nguồnbắt buộc nguồn synthetic; tối thiểu hai nến đã đóng
Thời gianUTC; open_time < close_time <= available_at <= as_of; khoảng mỗi nến bằng interval_seconds; nến không chồng nhau (cho phép khoảng trống)
Độ tươinến cuối không quá max_age_seconds do input khai báo
Sốhữu hạn, ≤ 12 chữ số có nghĩa, ≤ 6 chữ số thập phân, trị tuyệt đối ≤ 1.000.000.000
Filechỉ file local thường; từ chối ổ mạng, UNC, reparse point, file cloud chưa tải

2. Quy tắc minh hoạ

  • Lợi suất giữa hai nến cuối, đơn vị fraction.
  • Biến động vượt 5% so với giá đóng trước → risk_status: BREACH, ngược lại WITHIN_DEMO_THRESHOLD. So sánh chính xác trước khi làm tròn hiển thị.
  • Volume bằng 0 ở một trong hai nến → cảnh báo ZERO_VOLUME.
  • Luôn: mandate_status: REVIEW_REQUIRED, portfolio_compliance: UNKNOWN, rule_based: true, is_synthetic: true.

Ngưỡng 5% là ví dụ kỹ thuật, không phải ngưỡng đầu tư.

3. Dự báo

Hợp đồng ForecastRequest / ForecastResult có sẵn, --horizon 1–512 (mặc định 1). Chưa cấu hình adapter nên forecast luôn {"status": "unavailable"} — không bịa dự báo.

4. Đầu ra

FileNội dung
<run>/report.jsonphân tích, nguồn, đơn vị giá và tiền tệ, forecast, danh sách giới hạn
<run>/manifest.jsonSHA-256 của chính bytes input và report

Cùng input + tham số, tên run mới → cùng nội dung. Đích đã tồn tại bị từ chối, không ghi đè.

5. Thư mục làm việc

Phải là thư mục local đã có, ngoài repo, không reparse/cloud placeholder; chỉ nhận ổ Windows ánh xạ tới \Device\HarddiskVolume<n> (từ chối SUBST, ổ chuyển hướng). Tên run chỉ ASCII chữ, số, -, _; không dùng tên thiết bị Windows.

6. Mã lỗi và mã thoát

Mã lỗi ngắn, không lặp lại dữ liệu hay đường dẫn. Ví dụ hay gặp: path (file đầu vào không phải file local thường, ví dụ nằm trên OneDrive hay ổ mạng), json, schema, ohlcv, stale, temporal, text, workspace, platform, write. Danh sách đủ nằm trong fund_research/cli.py.

Mã thoátÝ nghĩa
0thành công
2input, workspace hoặc nền tảng không hợp lệ
3không xuất được

7. Dạng phân phối

CLI Python ≥ 3.12, chỉ thư viện chuẩn; xuất kết quả chỉ trên Windows. Không có skill hay manifest plugin. Chạy từ checkout: xem README.

Ngoài phạm vi hiện tại

Dữ liệu thị trường thật, chạy model dự báo, nhiều tài sản, danh mục, backtest, kết nối sàn hay môi giới.
