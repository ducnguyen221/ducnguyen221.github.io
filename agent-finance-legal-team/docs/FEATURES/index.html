Tính năng — agent-finance-legal-team

Nguyên mẫu CLI Python cho fixture tài chính–pháp lý tổng hợp. Một file JSON vào, một memo Markdown ra. Không mạng, không AI model, không dữ liệu thật.

Không dùng cho tư vấn tài chính hay pháp lý, dữ liệu khách hàng thật, phê duyệt hay quyết định tự động.

1. Kiểm fixture

KiểmHành vi
Kích thướcJSON UTF-8 ≤ 1 MiB, ≤ 10 cấp object/array
Cấu trúcschema đóng finance_legal_fixture_v1, mọi key bắt buộc; không key trùng, không NaN/Infinity
Số tiềnnull hoặc chuỗi thập phân ASCII ≤ 18 chữ số nguyên, ≤ 2 chữ số thập phân; không nhận JSON number, dấu cộng, số mũ
Văn bản≤ 100 assumptions, ≤ 100 findings, text ≤ 2.000 ký tự, ID ≤ 128; chuỗi bắt buộc không chỉ có khoảng trắng
Định danhfinding ID duy nhất; evidence ID duy nhất trên toàn fixture

2. Chênh lệch ngân sách

variance = actual − budget. Ra available khi đủ số và khớp kỳ, tiền tệ, đơn vị; ngược lại unknown kèm lý do:

missing_actual · missing_budget · period_mismatch · currency_mismatch · unit_mismatch

3. Kiểm metadata điều khoản

Mỗi finding ra eligible_for_review hoặc unknown kèm lý do:

missing_locator · missing_version · missing_jurisdiction · missing_effective_from · jurisdiction_mismatch · not_yet_effective · expired

eligible_for_review chỉ nghĩa là metadata khai báo đủ để người xem — không xác thực nguồn hay hiệu lực pháp lý. Trạng thái tổng luôn needs_review.

4. Memo

  • Kết quả tính nằm ngoài khối mã; fixture gốc giữ nguyên dạng JSON trong khối mã literal (CommonMark/GFM).
  • Cùng fixture → cùng memo.

5. Xuất file an toàn

  • Đích phải chưa tồn tại, thư mục cha có sẵn trên ổ cục bộ tin cậy; không tạo thư mục, không ghi đè.
  • Ghi temp cùng thư mục (.finance-legal-<tên>.tmp-…) rồi tạo hardlink độc quyền tới đích.
  • Từ chối UNC, đường thiết bị, alternate data stream, .., C:foo, symlink, reparse point; trên Windows còn từ chối ổ mạng ánh xạ, ổ subst, volume không phải đĩa cục bộ.

6. Mã lỗi

Thành công: exit 0, stdout/stderr rỗng. Thất bại: exit 2, stderr đúng một mã:

MãKhi nào
INPUT_ERRORđối số, đọc file, UTF-8, JSON, key trùng, kích thước, độ sâu
VALIDATION_ERRORschema hoặc nội dung fixture
OUTPUT_ERRORđường dẫn output hoặc ghi/link trước khi xuất
OUTPUT_PUBLISHED_CLEANUP_ERRORoutput đã xuất đủ nhưng temp còn lại — kiểm tay trước khi xoá

7. Dạng phân phối

CLI Python ≥ 3.11, chỉ thư viện chuẩn. Không có skill hay manifest plugin. Chạy từ checkout: xem README, hợp đồng, workflow.

Nguồn pháp lý thật, OCR, tra cứu văn bản, connector kế toán, vai trò chuyên sâu, phê duyệt.
