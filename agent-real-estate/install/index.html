Cài đặt

Chạy được memo đầu tiên từ bản checkout

Bạn cần Windows có PowerShell, Python 3.11 trở lên, Git và quyền truy cập mã nguồn do tác giả cấp. Công cụ chỉ dùng thư viện chuẩn Python, không cần cài thêm gói.

Lấy mã nguồn

Mã nguồn để riêng tư; liên kết chỉ mở được khi tài khoản GitHub của bạn đã được cấp quyền.

1

Xin quyền truy cập

Liên hệ tác giả Nguyễn Quang Đức qua ducnguyen.vn, gửi tên tài khoản GitHub của bạn.

2

Kiểm Python

Phiên bản in ra phải từ 3.11 trở lên.

PowerShell
python --version
3

Lấy mã nguồn bản 0.1.0.dev0

Lệnh lấy nhánh chính; tên thư mục ghi số bản để bạn dễ nhận.

PowerShell
# bản 0.1.0.dev0
git clone https://github.com/ducnguyen221/agent-real-estate.git agent-real-estate-0.1.0.dev0

Cảnh báo: chưa được cấp quyền thì lệnh clone báo «Repository not found» — đó không phải lỗi gõ lệnh, hãy chờ tác giả cấp quyền.

Chạy từ bản checkout

Không có bước cài gói: bạn trỏ Python vào thư mục src rồi chạy trực tiếp.

PowerShell
cd agent-real-estate-0.1.0.dev0
$env:PYTHONPATH = (Resolve-Path ./src).Path
cmd /c "python -m agent_real_estate < tests\fixtures\apartment.json"

Lưu ý: PowerShell không nhận dấu < để đưa file vào chương trình, vì vậy lệnh chạy qua cmd /c. Biến PYTHONPATH chỉ sống trong cửa sổ PowerShell hiện tại.

Kiểm sau khi cài

Cài đúng khi memo hiện ra và mã thoát bằng 0.

PowerShell
cmd /c "python -m agent_real_estate < tests\fixtures\house.json"
$LASTEXITCODE
# Đúng khi: dòng đầu là "# Synthetic residential screening",
# có "Decision status: needs_human_review" và số cuối cùng in ra là 0

Nâng cấp và gỡ

Nâng cấp

Kéo bản mới về thư mục checkout, rồi chạy lại lệnh kiểm.

PowerShell
git -C agent-real-estate-0.1.0.dev0 pull

Gỡ

Công cụ không cài gì vào hệ thống: xoá biến môi trường và thư mục checkout là xong.

PowerShell
Remove-Item Env:PYTHONPATH
Remove-Item -Recurse agent-real-estate-0.1.0.dev0

Lỗi hay gặp

Báo «No module named agent_real_estate»?

Đặt lại PYTHONPATH từ đúng thư mục gốc của bản checkout (nơi có thư mục src), trong cùng cửa sổ PowerShell sẽ chạy lệnh.

PowerShell báo dấu «<» bị dành riêng?

Bọc cả lệnh trong cmd /c "…" như ví dụ trên; PowerShell không chuyển hướng đầu vào bằng <.

Chỉ in ra invalid_input, mã thoát 2?

Hồ sơ JSON chưa đúng hợp đồng dữ liệu. So với hồ sơ mẫu trong tests\fixtures và đọc hợp đồng dữ liệu.

Python báo phiên bản không hỗ trợ cú pháp?

Cài Python 3.11 trở lên rồi mở cửa sổ PowerShell mới để python --version trỏ đúng bản.

Cài xong rồi?

Chuyển sang soạn hồ sơ tổng hợp của riêng bạn.
