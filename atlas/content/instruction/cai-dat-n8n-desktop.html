Cài Đặt n8n Trên Máy Tính Cá Nhân

Tự động hóa công việc cá nhân của bạn hoàn toàn miễn phí. Hướng dẫn chi tiết từng bước, đơn giản, trực quan và dễ hiểu dành cho tất cả mọi người (kể cả Non-Tech).

n8n là một công cụ tự động hóa quy trình (workflow automation) cực kỳ mạnh mẽ, giúp bạn kết nối các ứng dụng khác nhau (như Google Sheets, Gmail, Facebook, Telegram...) để tự động chạy các tác vụ lặp đi lặp lại.

Thay vì phải trả phí hàng tháng cho phiên bản Cloud, bạn hoàn toàn có thể tự cài đặt và chạy n8n ngay trên máy tính cá nhân của mình hoàn toàn miễn phí. Tài liệu này sẽ hướng dẫn bạn từng bước thực hiện điều đó một cách dễ hiểu nhất, ngay cả khi bạn không có kiến thức về lập trình.

Lưu ý quan trọng trước khi bắt đầu: Phiên bản phần mềm n8n Desktop (ứng dụng cài đặt bằng file .exe hoặc .dmg cũ) đã bị n8n ngừng phát triển từ tháng 5/2023. Hiện tại, để chạy n8n trên máy tính cá nhân ổn định, chúng ta sẽ sử dụng các phương pháp cài đặt chính thức dưới đây thông qua dòng lệnh đơn giản hoặc Docker.

1. Mô hình hoạt động của n8n trên máy tính cá nhân

Để bạn dễ hình dung, khi cài đặt n8n cục bộ (local), máy tính của bạn sẽ đóng vai trò là một "máy chủ" thu nhỏ:

  • n8n Engine: Chương trình chạy ngầm trên máy tính để xử lý các quy trình tự động hóa.
  • Trình duyệt Web (Chrome, Edge...): Nơi bạn thiết kế giao diện quy trình bằng cách kéo thả thông qua địa chỉ http://localhost:5678.
  • Cơ sở dữ liệu cục bộ (SQLite): File dữ liệu nằm ngay trên ổ cứng của bạn để lưu trữ các workflow và thông tin tài khoản an toàn.

Dưới đây là hai cách phổ biến nhất để chạy n8n trên máy tính cá nhân. Hãy click chọn phương pháp bạn quan tâm hoặc tham khảo bảng so sánh bên dưới:

Cách 1: Node.js & npx

Khởi động nhanh chóng chỉ với 1 dòng lệnh duy nhất, rất nhẹ và không tốn tài nguyên.

Cách 1: Cài đặt nhanh bằng Node.js & npx (Đơn giản nhất)

Cách này chỉ yêu cầu bạn tải một môi trường quản lý ứng dụng Javascript (Node.js) và chạy một dòng lệnh duy nhất để khởi động n8n.

1

Tải và cài đặt Node.js

  1. Truy cập trang web chính thức của Node.js: https://nodejs.org/.
  2. Tải bản LTS (bản hỗ trợ lâu dài, khuyên dùng để có độ ổn định tốt nhất).
  3. Mở file tải về (`.msi` trên Windows hoặc `.pkg` trên macOS) và tiến hành cài đặt bằng cách nhấn Next liên tục cho đến khi hoàn thành.
2

Khởi động n8n bằng Command Line

  • Trên Windows: Nhấn phím Windows (hoặc Start), gõ cmd rồi nhấn Enter để mở Command Prompt.
  • Trên macOS: Nhấn tổ hợp phím Cmd + Space, gõ Terminal rồi nhấn Enter.

Sao chép câu lệnh dưới đây, dán vào cửa sổ dòng lệnh và nhấn Enter:

bash / cmd
npx n8n

* Ở lần chạy đầu tiên, hệ thống sẽ hỏi bạn đồng ý cài đặt gói n8n không. Hãy gõ y (đồng ý) và nhấn Enter.
* Quá trình tải và thiết lập ban đầu có thể mất từ 1 - 2 phút tùy thuộc vào tốc độ mạng của bạn.

3

Truy cập giao diện quản trị n8n

Khi màn hình dòng lệnh hiện thông báo có chứa dòng chữ:

n8n ready. Open http://localhost:5678/

Hãy mở trình duyệt web bất kỳ (Chrome, Edge, Safari...) và truy cập địa chỉ sau:
👉 http://localhost:5678

Ở lần đăng nhập đầu tiên, n8n sẽ yêu cầu bạn tạo một tài khoản Quản trị viên (Email và Mật khẩu tùy ý) để bảo mật thông tin quy trình của bạn.

Điểm yếu của phương pháp này: Bạn phải luôn giữ cho cửa sổ Command Prompt/Terminal mở. Nếu vô tình tắt cửa sổ này hoặc tắt máy tính, n8n sẽ ngay lập tức ngừng hoạt động.

Cách 2: Cài đặt bằng Docker Desktop (Khuyên dùng lâu dài)

Docker giúp đóng gói n8n vào một môi trường cô lập ("container"). Điều này giúp n8n chạy cực kỳ ổn định, không bị ảnh hưởng bởi phần mềm khác và tự động chạy ngầm mỗi khi bạn mở máy.

1

Kiểm tra bật ảo hóa (Virtualization) trên Windows

Để chạy được Docker, máy tính Windows của bạn cần được bật ảo hóa trong BIOS.

  • Cách kiểm tra: Nhấn tổ hợp phím Ctrl + Shift + Esc để mở Task Manager -> Chọn tab Performance -> Nhìn góc dưới bên phải xem dòng Virtualization có đang ở trạng thái Enabled hay không.
  • Nếu là Disabled, bạn cần khởi động lại máy tính, truy cập BIOS và bật cài đặt Virtualization (VT-x / AMD-V) lên.
2

Tải và cài đặt Docker Desktop

  1. Truy cập trang chủ Docker: https://www.docker.com/products/docker-desktop/ và tải bộ cài đặt.
  2. Mở file cài đặt và làm theo hướng dẫn trên màn hình. Nếu hệ thống hỏi cài đặt WSL 2, hãy đồng ý và làm theo hướng dẫn liên kết để hoàn tất.
  3. Mở ứng dụng Docker Desktop vừa cài đặt, chấp nhận các điều khoản và để nó chạy ngầm (có biểu tượng chú cá voi ở khay hệ thống).
3

Tạo thư mục lưu trữ dữ liệu n8n

Khi cập nhật n8n hoặc tắt container, dữ liệu của bạn có thể bị mất nếu không lưu trữ ngoài. Chúng ta sẽ tạo một thư mục riêng để lưu trữ workflow an toàn:

Hãy tạo một thư mục trống tên là n8n_data tại phân vùng ổ đĩa mong muốn, ví dụ: C:\n8n_data (hoặc /Users/Username/n8n_data trên macOS).

4

Kích hoạt n8n bằng Docker lệnh

Mở Command Prompt hoặc Terminal, copy dòng lệnh dưới đây (chú ý đổi C:/n8n_data thành đường dẫn thực tế của thư mục bạn đã tạo ở Bước 3) và nhấn Enter:

Docker Run
docker run -d --name n8n -p 5678:5678 -v C:/n8n_data:/home/node/.n8n -e N8N_ENCRYPTION_KEY=my_secure_key_12345 --restart always docker.n8n.io/n8nio/n8n

Giải thích các tham số quan trọng trong dòng lệnh:

  • -d: Chạy ngầm chương trình (bạn có thể đóng cửa sổ CMD/Terminal thoải mái).
  • --name n8n: Đặt tên cho tiến trình container này là n8n để dễ quản lý.
  • -p 5678:5678: Liên kết cổng truy cập 5678 từ phần mềm ra trình duyệt web của bạn.
  • -v C:/n8n_data:/home/node/.n8n: Gắn ổ đĩa máy tính vào container để lưu trữ quy trình mãi mãi không mất đi.
  • --restart always: Cấu hình tự khởi động cùng máy tính của bạn khi mở máy.
5

Trải nghiệm n8n trên trình duyệt

Bây giờ, bạn chỉ cần mở trình duyệt và truy cập http://localhost:5678. Bạn có thể bật, tắt, hoặc xem các thông số hoạt động của n8n trực quan ngay trong ứng dụng giao diện đồ họa của Docker Desktop mà không cần mở Terminal nữa.

3. Các Mẹo Quan trọng cho Người dùng Cá nhân (Local)

Khi chạy n8n trên máy tính cá nhân thay vì máy chủ đám mây, bạn cần lưu ý một số vấn đề thực tế sau:

Mẹo 1: Khắc phục giới hạn Webhook cục bộ (Nhận dữ liệu từ ngoài Internet)

Giới hạn mạng: Địa chỉ IP local của bạn (localhost) là nội bộ. Các dịch vụ bên ngoài (như Telegram, Facebook, Google Sheets) không thể tự động đẩy dữ liệu (Webhook) về máy tính cá nhân của bạn nếu không được cấu hình định tuyến.

Giải pháp tối ưu và đơn giản nhất (Sử dụng ngrok):

  1. Tải công cụ đường ống bảo mật miễn phí ngrok tại: https://ngrok.com/.
  2. Khởi chạy ngrok để tạo một đường dẫn kết nối công khai nối trực tiếp vào cổng n8n cục bộ bằng câu lệnh:
    ngrok console
    ngrok http 5678
  3. ngrok sẽ tạo một đường dẫn an toàn dạng https://xxxx-xxxx.ngrok-free.app. Hãy copy link này để làm Webhook URL cấu hình trên các API dịch vụ ngoài. Hệ thống bên ngoài sẽ gửi thông tin thông suốt về máy bạn.

Mẹo 2: Sao lưu (Backup) quy trình của bạn thường xuyên

Để đảm bảo không bị mất công sức thiết kế các workflow, hãy thực hiện sao lưu bằng các cách sau:

  • Xuất file trực tiếp từ giao diện n8n: Ở góc trên bên phải giao diện thiết kế workflow -> chọn Export Workflow để tải file định dạng .json về máy tính.
  • Sao lưu thư mục gốc: Nếu sử dụng phương pháp Docker, hãy copy thư mục n8n_data cất vào Google Drive, OneDrive hoặc USB cá nhân định kỳ.

Mẹo 3: Cập nhật n8n lên phiên bản mới nhất

  • Nếu dùng Node.js: Nhấn tổ hợp phím Ctrl + C trong Terminal để tắt n8n đang chạy, sau đó chạy lại lệnh khởi động ban đầu. Hệ thống sẽ tự động cập nhật bản mới nhất.
  • Nếu dùng Docker Desktop:
    1. Mở Docker Desktop -> Tab Containers -> Bấm Stop và bấm Delete container n8n cũ.
    2. Mở dòng lệnh chạy lại câu lệnh ở Bước 4 của Cách 2. Docker sẽ tải bản mới nhất về khởi tạo lại. Các workflow cũ không bị mất vì đã được map lưu trữ riêng ở thư mục n8n_data trên ổ đĩa máy tính.

Kết luận & Khuyến nghị

Nếu mục tiêu của bạn chỉ là muốn trải nghiệm thử n8n xem các tính năng hoạt động ra sao, hãy chọn Cách 1 (Node.js) để nhanh chóng có n8n chạy trong vòng chưa đầy 3 phút.

Nếu bạn xác định sử dụng n8n để phục vụ các công việc hàng ngày lâu dài và tự động, hãy dành thêm thời gian cài đặt theo Cách 2 (Docker Desktop). Ổn định, an toàn và tự khởi động chạy ngầm sẽ giúp tối ưu năng suất làm việc của bạn mà không phải lo lắng về việc duy trì các cửa sổ Terminal phức tạp.

Chúc bạn thiết lập thành công và tạo nên những quy trình tự động hóa tuyệt vời để giải phóng sức lao động!
